## About me

I build projects at the intersection of robotics, mechatronics and automation. My work brings together sensors, embedded programming, control logic and mechanical systems to solve practical engineering problems.

My portfolio includes mobile robots, robotic manipulation, manufacturing applications and computer vision for automated inspection.

## Selected projects

### Glass bottle inspection
Final year project exploring bottle crack detection using HOG with Logistic Regression, HOG with Random Forest, and ResNet18. The repository includes dataset samples, training code, evaluation results and model comparisons.

<a href="https://github.com/Kaveesha229/Design%2DDevelopment%2Dof%2DVision%2DBased%2DBottle%2Dtype%2DCrack%2Didentification%2Dand%2Drejection%2Dfor%2DGlass%2Dbottles">Explore the inspection project</a>

### Mobile robot with pick and place
A PID line following robot with a two axis robotic arm, colour sensing and image processing. The system combines ESP32, Arduino Nano and an ESP camera module.

<a href="https://github.com/Kaveesha229/KDU%2DMSD%2DLine%2Dfollowing%2Drobot%2Dwith%2Dpick%2Dand%2Dplace%2Dusing%2Dcolor%2Dsensor%2Dand%2Dimage%2Dprocessing">Explore the robotics project</a>

### ROSCO 2025 competition robot
Team KETHAKARU achieved second place at ROSCO 2025 at KDU. The robot tackled line following, wall following, inverted line following and a ramp challenge.

<a href="https://github.com/Kaveesha229/KDU%2DRosco%2D2025">Explore the competition robot</a>

### Manufacturing automation
Embedded cutter cycle counting and cover seam ringer automation, including PLC programs, an HMI project and wiring documentation.

<a href="https://github.com/Kaveesha229/Chopper%2Dcut%2Dlife%2Dcounter">Explore the cutter life counter</a> &nbsp; | &nbsp; <a href="https://github.com/Kaveesha229/Cover%2DSeam%2DRinger%2DAutomate">Explore the manufacturing repository</a>
